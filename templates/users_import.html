1. Download teacher template

The spreadsheet allows you to quickly list your school's teachers. Download the ready-to-use template in Excel or CSV format:

Supported Columns: Full Name | TSC Number | Username | Phone | Initials | Role | Temporary Password
  • Full Name: Required (e.g. Grace Wanjiku or Mr. Peter Kamau).
  • TSC Number: Recommended Teachers Service Commission registration number (e.g. 123456).
  • Username: Optional. If blank, system auto-generates a clean unique username (e.g. gwanjiku).
  • Phone: Optional contact phone number (e.g. 0712345678).
  • Initials: Optional. If blank, auto-generated from their name (e.g. GW) for report cards.
  • Role: Optional. Teacher, Head Teacher, Deputy Head Teacher, Exam Officer, Viewer, or Admin (defaults to Teacher).
  • Temporary Password: Optional. If blank, the system uses the default password specified below.
  • Security: All uploaded teachers will be required to choose a new password when they first log in.
