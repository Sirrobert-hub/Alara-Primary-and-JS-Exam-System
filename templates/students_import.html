Upload students from Excel or CSV

Import learners into the system using Excel spreadsheet or CSV file with the standard national/CBC student schema.

1. Download student template

The file must follow the standard 10-column layout below. You can download the pre-formatted Excel or CSV template ready to fill in:

Required Column Format: Admission No | Unique Learner Identifier (ULI) | ASSESSMENT NO. | Full Name | Gender | Grade | Stream | Date of Birth | Guardian | Phone
  • Admission No & Full Name are required. Admission numbers must be unique.
  • Unique Learner Identifier (ULI): NEMIS / UPI / ULI code for CBC tracking.
  • ASSESSMENT NO.: National index / CBA assessment number (e.g. KPSEA).
  • Grade & Stream: Class name (e.g. Grade 7) and stream (e.g. East).
  • Gender: M (Male) or F (Female).
  • Date of Birth: Standard date format (e.g. 2012-05-18 or 18/05/2012).
Download Excel (.xlsx) Download CSV (.csv)

2. Upload your file

Choose your filled-in .xlsx or .csv spreadsheet to upload.

Accepts Microsoft Excel (.xlsx, .xlsm) and CSV files.
